# DESIGN.md — 《给整个集群发号的人》

## 全局视觉约定

**画布**：1280×720，padding 60（上下左右），内容区 1160×600。

**配色（科技蓝，单一强调色）**

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#2563EB` | 编号、流程节点、主标题强调 |
| 深色 | `#0F2A5C` | 深色面板（全篇每页 ≤1 处） |
| 辅色 | `#EFF6FF` / `#F1F5F9` | 浅底卡、结论条 |
| 强调 | `#F59E0B`（块）/ `#B45309`（文字） | 关键数字、关键句，一页 ≤3 处 |
| 正文 | `#0F172A` 标题 / `#334155` 正文 / `#64748B` 注释 | — |
| 线 | `#E2E8F0` | 1px 分区细线 |

**字体**：中文 微软雅黑；西文 Arial。整篇一个家族，字重只用 Regular / Bold。

**字号阶梯**：封面 84 / 巨型数字 200 / 页面主标 40 / 卡片小标 22–24 / 正文 18 / 注释 14–15。

**视觉母题**：每个内容页左上角「NN / 小节名」眉标 + 一条贯通到右边界 1px 细线；页码固定在右下（y≈690，14px）。封面、结尾页无页尾。

**配图策略**：全篇视觉类型统一为「矢量图解」（架构图 / 流程链 / 对照结构），不使用照片，避免风格混入。
